# Joga Batrīsī: digital edition

Working repository for the critical edition of the *Joga Batrīsī* (colophon title in witness N: *Ātmajñāna-dvātriṃśikā*), a thirty-two-verse Jain yoga poem in Maru-Gurjar (Old Gujarati) attributed to Pārśvacandra (1480–1555). Chapter IV of the cumulative dissertation of Corinna May Lhoir (Ghent University / Universität Hamburg).

## Witnesses

| Siglum | Manuscript | Date | Place |
|---|---|---|---|
| A | AKGM 145480, Ācārya Śrī Kailāsasāgarasūri Jñānamandir, Koba | VS 1683 (1627 CE) | Pattana (Pāṭaṇ) |
| N | Nani Khakhar (Kutch), Pārśvacandra-gaccha | undated | |

A is a multiple-text manuscript of two folios (four works); only the first work is transcribed here. N has 33 verses, A has 32.

## Contents

- `tei/` TEI P5 files, one per witness, following the encoding of the [TST project](https://tst-project.github.io/) (editor: [tst-project.github.io/editor](https://tst-project.github.io/editor/)). Transcriptions are diplomatic, in IAST; the Devanāgarī view is generated by the editor.
- `txt/` plain-text transcriptions (Devanāgarī and IAST, one half-verse per line, tab-separated with a verse key such as `JB5a`).
- `scripts/deva2tst.py` converts a Devanāgarī transcription into IAST with the TST conventions (vowel hiatus marked with diaeresis: *lābhaï* = लाभइ as against *lābhai* = लाभै).

## Conventions

- Verses are encoded as `<lg n="…">` with two `<l>` (half-verses a and b).
- Manuscript line breaks are `<lb n="…"/>`; `break="no"` marks a break inside a word.
- Language tags: `gu` for the verses (Maru-Gurjar; no ISO code exists for Old Gujarati), `sa` for rubrics and colophons.
